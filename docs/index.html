02 / PRØV MED DIN EGEN PDF

Dit dokument.
Din næste samtale.

Åbn appen online, upload en PDF og stil dit første spørgsmål. Ingen installation nødvendig. Brug et dokument uden private oplysninger.

Åbn PDF-assistenten ↗

Gratis testversion: højst 5 MB og 60 sider, med ord- og frasesøgning. Du kan også køre den fulde version lokalt ↗.

VALGFRIT: START LOKALT
git clone https://github.com/oumar969/Chat_with_your_PDF.git
cd Chat_with_your_PDF
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.lock
.venv\Scripts\python -m streamlit run app.py

Indsæt din egen Gemini-nøgle i en lokal .env-fil. Se README for gratis kvoter og opsætning.
